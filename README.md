# منصة البحث في الملفات وقواعد البيانات

تطبيق ويب عصري ومتجاوب مبني باستخدام **React 18** و **Vite**، مُصمم بالكامل بناءً على صور التصميم المرجعية لنظام البحث في الملفات والأحكام والوثائق القانونية.

---

## 🌟 المميزات المكتملة

1. **واجهة البحث البسيط (مطابقة لصورة pic1):**
   * شريط عنوان بتصميم سهم أنيق (`SectionRibbon`).
   * اختيار متعدد لقواعد البيانات عبر شرائح تفاعلية (`Chips`) مع عدّاد النتائج وزر "تحديد الكل / إلغاء الكل".
   * حقل إدخال مرن للبحث مع زر مسح سريع.
   * زرا "شروع البحث" و "مسح".

2. **واجهة البحث المتقدم (مطابقة لصورة pic2):**
   * شبكة فلاتر دقيقة: الكلمات المفتاحية، قاعدة البيانات، المصدر، نوع الملف، رقم الملف، نطاق السنوات (من سنة / إلى سنة).
   * خيارات مطابقة الكلمات (جميع الكلمات / أي كلمة / العبارة كما هي).
   * مفتاح تبديل للبحث في النص الكامل (`Full-Text Toggle`).
   * ترتيب النتائج (الأكثر صلة / الأحدث / الأقدم).
   * زر بحث بعرض كامل وزر لإعادة التعيين.

3. **جدول النتائج:**
   * رأس الجدول باللون الأزرق الفولاذي كما في الصورة المرجعية.
   * الأعمدة: رقم الملف، عنوان الملف وخلاصته مع تمييز كلمات البحث (`Highlighting`)، قاعدة البيانات، المصدر، النوع، التاريخ، وزر "عرض".
   * تحول تلقائي إلى بطاقات ذكية عند فتح الموقع من الهواتف المحمولة.
   * تقسيم النتائج لصفحات (`Pagination`) واختيار عدد النتائج لكل صفحة (10 / 20 / 50).
   * عرض حالات التحميل (Skeleton)، وحالة "لا توجد بيانات"، وحالة الخطأ مع زر إعادة المحاولة.

4. **صفحة عرض تفاصيل الملف (`/files/:id`):**
   * بطاقة تعريفية برقم الملف، المصدر، التاريخ، عدد الصفحات، والكلمات الدلالية.
   * أزرار سريعة لنسخ رقم الملف، نسخ رابط المشاركة، وطباعة الوثيقة (`Print Sheet`).
   * زر للعودة السلسة لنتائج البحث مع الاحتفاظ بكافة الفلاتر كما هي.

5. **المعمارية وطبقة الخدمات (Architecture):**
   * فصل تام للمسؤوليات (Clean MVC Principles).
   * دعم اتجاه RTL الكامل وخط Cairo العربي.
   * طبقة Mock Server تجريبية تحاكي استجابة الـ Backend لتمكين العرض للعميل فوراً دون أي backend.
   * جاهزية تامة للربط الفعلي بـ Backend حقيقي عبر متغير بيئي واحد (`VITE_USE_MOCK=false`).

## 🚀 التثبيت والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على العنوان: `http://localhost:5173/`

### 3. بناء نسخة الإنتاج:
```bash
npm run build
```

---

## 🔌 الربط بالـ Backend مستقبلاً

عند اكتمال الـ Backend (مثل ASP.NET Core API):
1. افتح ملف `.env`.
2. حدّث عنوان الـ API:
   ```env
   VITE_API_BASE_URL=https://api.yourdomain.com/api
   VITE_USE_MOCK=false
   ```
3. أعد تشغيل التطبيق. ستتحول كل العمليات تلقائياً إلى خادم الـ Backend الحقيقي دون أي تعديل في واجهات المستخدم!
4. راجع ملف [docs/API_CONTRACT.md](docs/API_CONTRACT.md) للاطلاع على مواصفات مسارات الـ API.

## 📁 هيكلية المشروع

```text
src/
├── assets/          # الأيقونات والشعارات
├── components/      # المكونات
│   ├── common/      # أزرار، بطاقات، ترقيم، حالات الخطأ والتحميل
│   ├── forms/       # حقول الإدخال، القوائم المنسدلة، أزرار الاختيار، التبديل
│   ├── layout/      # الرأس، التذييل، شريط وضع العرض التجريبي
│   └── search/      # اختيار قواعد البيانات، جدول النتائج، لوحة النتائج
├── context/         # نظام الإشعارات المنبثقة (Toast Context)
├── hooks/           # خطافات إدارة الحالة، استدعاء البيانات، والتحكم بالرابط
├── layouts/         # قالب الصفحة الرئيسي (MainLayout)
├── pages/           # صفحات البحث البسيط، البحث المتقدم، وتفاصيل الملف
├── routes/          # المسارات والتنقل
├── services/        # إعدادات الاتصال، مسارات API، والخادم التجريبي (Mock Server)
├── styles/          # المتغيرات، الألوان، ونظام التصميم العام (RTL)
├── utils/           # معالجة النصوص العربية، التحقق من المدخلات، التنسيق
├── App.jsx
└── main.jsx
```
